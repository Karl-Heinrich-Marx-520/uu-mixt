## 2. E1 桌宠接线

### 2.1 交互规格全集（验收基准，勿改）

- 常驻左下角（`left:16 bottom:14`），点击开对话栏；按住拖动（位移 >6px 判拖动，`justDragged` 抑制拖动后的合成 click）；位置记忆（刷新不丢），resize 自动拉回视口。
- 对话栏 344px 宽：**手动拖放优先**（落点记忆），否则四向跟随小鹿——**上 → 右 → 左 → 下**（小鹿在顶部时贴身走侧向）；拖小鹿 = 清固定存档回到跟随；拖对话栏 = 固定并记忆。
- 回答范围严格限本站：规则式检索内容层，检索不到明示拒答并给建议问法（PRD E1 范围约束，正式 LLM 版同样要守）。
- 动作动画（全部挂 `img`，脚底支点 `transform-origin: 50% 100%`）：
  - idle 随机：摇摆 wiggle ±6° / 跳跃 hop / 张望 look ±7px±4°（1.2s）/ 转身 flip（scaleX 1→-1→1，1.2s）；首发 3.5-6s，之后每 7-15s；对话栏打开或拖拽中不插动作。
  - 事件动作：开框 hop；回答 nod；拖动落地 land；拖拽中持续 dangle（纯 CSS）。
- **随机漫步 stroll**：首发 12-20s，之后每 15-30s；单程水平 ±120-360px / 垂直 ±80-280px（clamp 视口 8px 边距，落点距当前 <48×48 跳过）；走路颠簸 0.34s 循环 + **面朝移动方向**（原图朝左，向右走镜像）；点击/按住**就地冻结停步**（不瞬移到目标点）；散步位置不持久化。
- reduced-motion：`.pet` 浮动、img 全部动作、stroll 过渡全禁。
- 首访气泡提示（打开过一次就不再提示）。

### 2.3 正式站改动点

1. **资产**：`pet.js` → 正式站脚本（建议 `src/scripts/pet.js` 经 Astro 引入，或 `public/scripts/pet.js` 原样 + `<script is:inline defer>`）；`pet.png` → `public/images/`。两处 `<img src>` 路径同步改。
2. **内容层契约（唯一接口依赖）**：pet.js 只调用 `store.published(face)`，只读字段 `slug / title / face / detail?`。正式站用**构建期生成的全站文章索引 JSON**（可直接复用搜索索引产物，决策 7.13）注入 `window.UUMIndex` 或等价全局，pet.js 开头的数据源适配点在 `var store = window.UUMStore || null` 一行——换成正式索引适配器即可，回答引擎零改动。
3. **LLM 升级（可独立成第二批）**：规则引擎先原样上线（零 API 成本验证需求）；E1 正式版换 Go 小服务 LLM 转发端点（`docs/06`），**范围约束、UI 行为、拒答话术全部保留**。前端只改 `respond()`：改为 POST 端点 + 打字机气泡；超时/失败降级回规则引擎。Key 与限流在服务端。
   **供应商已定（2026-09-15，决策 7.17）：DeepSeek**——OpenAI 兼容 `/chat/completions` 格式，Go 小服务持有 Key 并做转发与限流，前端只见自家端点；模型与温度等参数由服务端配置，前端不感知。
4. **Astro 组件化**：做成 `Pet.astro`（DOM 模板 + 脚本），在共享 layout 引入一次；注意 Astro 默认打包 script，需要保留 IIFE 立即执行语义时用 `is:inline` 或确认打包产物等价。
5. **z-index 契约**（新浮层必须对齐，见 §5.4 表）。
6. **预算**：pet.js 20.2KB 源码 + pet.png 56.8KB（预算 400KB 内）。桌宠**不属于首屏关键路径**：defer / 动态 import 加载，不占「入口页关键 JS ≤15KB」预算（该预算只算关键路径，当前实测 9.4KB）。

## 5. 工程须知（本工作流实战踩坑，接正式站同样适用）

### 5.1 挂载点：挂 `<html>` 不挂 body

面页 body 带 `perspective`（翻转动画用）→ body 成为 fixed 后代的包含块 → 浮层会被钉到**整页底部**而非视口。桌宠、对话栏、友链卡组、牌堆全部 `documentElement.appendChild` + `position:fixed`。Astro 里如果放进某个带 transform/perspective 的容器一样会中招。

### 5.2 animation 会覆盖 transform

`flipped` 朝向（`scaleX(-1)`）与走路颠簸动画同层时互相吃掉。解法：**镜像写进专用 keyframes**（`pet-walk-flipped`：每帧自带 `scaleX(-1)`）。任何「既要动画又要持久 transform」的场景都按此模式拆。

### 5.3 transition 中断的冻结模式

元素处于 left/top 过渡中时，`getBoundingClientRect()` 返回**插值中的视觉位置**。中断动画 = 先把 rect 落成 `left/top` 内联样式、再移除过渡类——元素停在当前位置而非瞬移到终点（桌宠散步被点击/按住中断即此实现）。

### 5.4 z-index 层级契约表（新增浮层必须对齐）

| 层 | z-index |
|---|---|
| 拖拽中的元素（`.is-dragging` / zoomed 卡） | 900 |
| 桌宠 `.pet` / 对话栏 `.pet-drawer` | 860 |
| 入口页 `entry-hint` / `entry-foot`（文字浮层保护） | 850 |
| 友链牌堆 `.friend-deck` | 800 |
| 场上友链卡 | 10+i（后发压先发），退场垫 5 |

### 5.5 双层动画架构

外层 `.pet` 承担浮动 bob / hover scale / is-active 暂停；动作动画全挂内层 `img`（脚底支点）。两层 transform 互不覆盖——新增动作动画时沿用此分层，别往 `.pet` 上堆 animation。

### 5.6 测试纪律

- **localStorage 跨页联动的验证必须走 http 同源**（demo 验收服务器 `python -m http.server 8207`，正式站走 dev server）。无头浏览器的 file:// 各页 localStorage 互相隔离，会得出「写入丢失」的假象。
- agent-browser：单次 eval 上限约 30s（超时报 os error 10060）；跨 Bash 调用页面上下文会漂移——**open + eval 链在同一条 shell 命令里**；无限 CSS 动画会卡死 snapshot/screenshot，断言全走 eval；需要确定性随机时注入 `Math.random` 桩（例：恒 0.9 → 散步固定向右 ~269px）。

### 5.7 版本号与缓存

Demo 内手工 `?v=N` 防缓存（当前 css v15 / store v8 / friends v5 / pet v7 / demo.js v10）。**正式站交给 Astro 构建产物 hash，不需要手工维护**；但从 demo 抄代码时别把 `?v=` 参数语义理解成正式站必需。
