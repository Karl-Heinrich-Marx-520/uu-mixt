| 规格 | 实现与实测 |

## 附 A · 自检脚本（`scripts/check-pages.mjs`）

本轮把三类真实踩过的坑固化为断言，失败即非零退出：

| 断言 | 触发过的真实问题 |
|---|---|
| 逐路由 `body[data-face]` 身份 | Mixt 面镜像时漏改 `face` → 用错背景与主题色 |
| **空白页检测**（可见文本 < 80 字符 / 缺 `<main>` / 残留 `<!---`） | `search.astro` 的 frontmatter 定界符误写成 `<!---` → 构建"成功"但页面空白 |
| 站内死链 | 遗漏 `/mixt/categories/` 时被抓住 |
| 交付件齐全（3 份 RSS / sitemap / robots / 搜索索引）与 sitemap 不含 `/admin/` | — |

## 附 B · 本包发现并修复的缺陷

1. **搜索页空白**（严重）：`search.astro` 首行写成 `<!---`（多一个 `!`），Astro 未解析 frontmatter，整份源码被浏览器当未闭合注释吞掉 → 页面全空白。已修，并新增空白页断言防复发。
2. **写作台提示条图标失控**：`.notice` 样式此前只存在于 `article.css`，写作台未引入该文件 → 内部 SVG 失去尺寸约束被撑成整屏大小（用户反馈的"超大圆圈"）。已把 `.notice` 移入共享的 `components.css`。
3. **写作台 URL 字段冗余**：文章与分类表单里的 URL 短名输入框全部移除，改为静默自动生成（英文 → kebab；中文 → 日期兜底；同面自动去重；已发布保持冻结）；分类列表不再显示短名。
