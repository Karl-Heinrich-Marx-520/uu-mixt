## 2. 阶段一：服务器初始化

> 目标：拿到一台「SSH 免密、系统干净、防火墙最小开口」的机器。全程约 15 分钟。

**你需要提供**（凭据走会话直传或 `deploy.local.sh`，**绝不入库**，AGENTS.md §6）：

1. 服务器公网 IP
2. SSH 访问方式：root 密码（首登后立即改用密钥）或已配置的密钥
3. 阿里云轻量控制台防火墙：放行 **TCP 8080**（预览期）；80/443 备案通过后再开

**执行清单**（我代劳或你复制粘贴均可）：

```bash
# ① 系统更新（Ubuntu 24.04）
apt update && apt upgrade -y

# ② 基础工具
apt install -y nginx rsync certbot python3-certbot-nginx curl

# ③ SSH 加固：密钥登录 + 关密码（先确认密钥能登，再关！）
#    本地执行 ssh-copy-id root@<IP> 后，编辑 /etc/ssh/sshd_config：
#    PasswordAuthentication no
#    PermitRootLogin prohibit-password
systemctl restart ssh

# ④ 可选但推荐：fail2ban（防 SSH 爆破，零维护）
apt install -y fail2ban

# ⑤ 轻量服务器内存充裕，无需 swap；确认内存基线
free -h   # 预期可用 ~1.8G
```

目录约定（写入 Nginx 配置与 deploy.local.sh）：

| 路径 | 用途 |
|---|---|
| `/srv/uum/dist` | 站点根（rsync 目标） |
| `/etc/nginx/sites-available/uum.conf` | 站点配置 |

> T4 之前**不放任何仓库与内容源码**上服务器；`/srv/uum/repo.git` 主库属 §5 批次，届时建立，且**不得位于站点根下**（防止源码被直接下载，docs/06 §4.3）。

## 3. 阶段二：Nginx 8080 预览部署（备案期间）

### 3.1 Nginx 配置（8080 预览版，直接可用）

`/etc/nginx/sites-available/uum.conf`：

```nginx
server {
    listen 8080;
    server_name _;
    root /srv/uum/dist;
    index index.html;

    # 目录式路由：/uu/posts/xxx/ → index.html；无尾斜杠自动 301 补齐
    location / {
        try_files $uri $uri/ =404;
    }

    # 带 hash 的构建资源：一年强缓存
    location /_astro/ {
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    # HTML 不缓存（发布即时可见）
    location ~* \.html$ {
        add_header Cache-Control "no-cache";
    }

    # 搜索索引：短缓存（每次构建后体积会变）
    location = /search-index.json {
        add_header Cache-Control "public, max-age=300";
    }

    gzip on;
    gzip_types text/html text/css application/javascript application/json image/svg+xml;
    gzip_min_length 1024;
}

# 站点根之外：禁看隐藏文件（保险）
server { listen 8080; location ~ /\. { return 404; } }
```

启用：

```bash
ln -s /etc/nginx/sites-available/uum.conf /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

### 3.2 deploy.sh（一条命令，符合 AGENTS.md §5 三条纪律）

`scripts/deploy.sh`（**无凭据版，可入库**）：

```bash
#!/usr/bin/env bash
# UU&Mixt 部署：本地 dist/ → 服务器。凭据在 deploy.local.sh（不入库）。
set -euo pipefail
cd "$(dirname "$0")/.."

# deploy.local.sh 必须提供：DEPLOY_HOST / DEPLOY_USER / DEPLOY_PORT（可选）
source deploy.local.sh

node scripts/check-pages.mjs          # 部署前自检，失败即停（失败可见）
npm run build

rsync -az --delete --stats \
  --rsync-path="mkdir -p /srv/uum/dist && rsync" \
  -e "ssh -p ${DEPLOY_PORT:-22}" \
  dist/ "$DEPLOY_USER@$DEPLOY_HOST:/srv/uum/dist/"

echo "✅ 部署完成：http://$DEPLOY_HOST:8080"
```

`deploy.local.sh`（gitignore 已忽略）：

```bash
DEPLOY_HOST='<IP>'
DEPLOY_USER='root'
DEPLOY_PORT='22'
```

三条纪律的落实：成功打印同步文件数与目标（`--stats`）；失败非零退出（`set -e` + 自检前置）；`--delete` 清理服务器上已不存在的旧文件。

### 3.3 部署验收清单（master 执行后逐项核对）

- [ ] `http://<IP>:8080/` 入口页两卡可见、翻牌动画正常
- [ ] `http://<IP>:8080/uu/` 与 `/mixt/` 直接访问不播动画、主题色与背景各自正确
- [ ] 任一文章页打开正常（Markdown 渲染 + 目录 + 代码块）
- [ ] `robots.txt` / `sitemap-index.xml` / `rss.xml` 可访问
- [ ] 桌宠常驻左下角可对话，「最近更新」返回真实文章
- [ ] `/admin/` 登录门可访问（预览期可用性取决于作者本机连 GitHub 的网络）
- [ ] 404 页正常
- [ ] 全程走 IP:8080，**域名不解析**（备案铁律）

### 4.2 Mixt（或 UU）写作台发文


| 改动 | 谁做 | 到线上的路径 |

### 5.1 服务器侧：Go 小服务规格（照 docs/06 §4.2 + 7.17）

| 项 | 规格 |
|---|---|
| 进程 | Go 单二进制（编译本地交叉产出，服务器免工具链）；systemd 守护；只监听 `127.0.0.1:8787` |
| 写入 API | `POST /api/write`、`GET /api/read|list`、`DELETE /api/file`——与 gh.js 8 函数语义一一对应；face 由 token 推导，接口不接受 face 参数；路径白名单 + 限流 + 单文件上限 |
| LLM 转发 | `POST /api/chat`（7.18 实现端点）：服务端持有 **API Key**（OpenAI 兼容 `/chat/completions`，供应商可插拔）；模型/温度/System prompt 全在服务端配置，前端不感知；实现见 `pet-server/`（含 per-IP 限流 + 日配额 + 同题缓存） |
| 范围约束 | System prompt 硬约束「只聊博客」+ 检索上下文注入（直接用 `search-index.json` 的命中条目作 prompt 素材，站内量级不需要向量库）+ 输出侧兜底；**拒答话术与规则版一致** |
| 降级 | 端点超时/失败 → 前端 `respond()` 降级回规则引擎（docs/07 §2.3-3 已定） |
| 限流 | 每 IP 每分钟 N 次 + 全站日配额；429 明确文案 |
| 密钥 | DeepSeek Key 与作者 token hash 放 `/etc/uum/uum.env`（`chmod 600`），systemd `EnvironmentFile` 加载 |
| 内存 | < 50MB；预算表更新为「Nginx ~10MB + 小服务 ~50MB」，200MB 桌宠预留继续保留 |

### 5.2 Nginx 反代（443 server 块内追加）

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8787;
    proxy_read_timeout 30s;
    client_max_body_size 4m;   # 图片上传 multipart

```

### 5.3 部署步骤摘要

1. 本地交叉编译 Go 二进制 → rsync 上服务器 → `/etc/uum/` 放 env → systemd unit 启用
2. Nginx 追加 `/api/` 反代 → reload
3. 前端批次（UI 窗口）：新增 `public/scripts/admin/server.js`（同 8 函数接口替换 gh.js）+ `pet.js respond()` 改 POST 端点 + 打字机气泡
4. 两位作者真实发文验证（docs/06 实施顺序第⑤步）
5. 服务器 cron：每 6h `git push --mirror` GitHub（备份，失败只告警）

## 6. 故障速查

| 症状 | 排查顺序 |
|---|---|
| 8080 打不开 | 阿里云控制台防火墙开了 8080？→ `nginx -t` → `systemctl status nginx` → `ss -tlnp | grep 8080` |
| 页面更新了但没变化 | 浏览器强刷（HTML 已设 no-cache，一般为本地缓存）；确认 deploy 输出的同步文件数 > 0 |
| deploy.sh 卡住/失败 | ssh 手动登一次（首次 host key 确认）；看报错行——**失败必须可见**，禁止静默重试掩盖 |
| 写作台登录 401/403 | PAT 过期（401）/未勾 Contents: Read and write（403）；Mixt 用 classic PAT（PRD 3.8） |
| 证书到期 | certbot 装 nginx 插件后自动续期；`certbot renew --dry-run` 验证 |
| 磁盘告警 | `du -sh /srv/uum/dist`（产物应 <50MB）；rsync `--delete` 已防僵尸堆积 |
