# 前端 Demo（阶段 2.3 · 无后端模拟实现）

> 参考站点：[rocketma.dev](https://rocketma.dev/) · [skipshot.cn](https://skipshot.cn/)
> 定位：**验证视觉风格与交互体验的静态原型**，非最终实现。与 PRD 的正式实现（Astro + Tailwind）技术栈无关。

## 运行方式

**方式一（推荐）**：在 `demo/` 目录起一个静态服务：

```bash
cd demo
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式二**：直接双击 `index.html`（file:// 协议下所有页面与交互同样可用，复制链接功能会走降级路径）。

## 内容层与写作台（v2）

Demo 自带一个**本地内容层**（`assets/demo-store.js`，数据存 localStorage），让「写作台提交 → 站点立即可见」形成完整闭环，无需任何后端：

| 能力 | 说明 |
|---|---|
| 提交即发布 | 写作台保存（非草稿）→ 面首页、归档、分类页立刻出现；新发布文章带「新发布」徽章 48 小时 |
| 两把密码 | 写作台按密码区分身份：UU 面 `uu2026`、Mixt 面 `mixt2026`；进去后**只能管自己那一面**（作者字段锁定） |
| 分类自维护 | 每面维护自己的分类（增/改/删）；改名会同步该分类下文章的标签；Mixt 面初始为空 |
| 直接进入 | 调试/演示可用 `admin.html?face=uu`（或 `?face=mixt`）跳过输入密码 |
| 数据自清 | 写作台「设置」里可导出本面 JSON、或重置为初始数据 |

**为什么用 localStorage 而不是真后端**：正式实现里文章就是仓库里的 Markdown，构建期读取。Demo 用本地存储把**接口语义**（提交即发布、分类自维护、面间隔离）先固定下来，后续照这个 Demo 接线即可。

## 设计与实现的对应关系

| 参考站特征 | Demo 落点 |
|---|---|
| skipshot：卡片含置顶徽章、日期、字数、阅读时长、`[分类] 标题`、单行摘要 | `.post-card` 元信息行完整复刻 |
| rocketma：信息密度高、标签竖线分隔、分类/标签双维度、分页 | 摘要保留双行截断；分页与归档筛选 |
| 两站共有的 Hexo 系交互：暗色切换、卡片悬浮抬升、代码块体验 | 暗色切换（持久化）、hover 抬升 3px、深色代码块 + 行号 + 一键复制 |
| **本项目特有**：双面隔离、翻转、入口页仪式感 | 面主题色由 CSS 变量驱动（取自两位作者头像占位 SVG 的主色）；翻面控件（按钮 / Alt+←/→ / 触屏滑动）；直接打开面页面无动画（PRD 4.2） |

## 关键假设（评审时请重点确认）

1. **流程**：按协作流程本应先完成 2.2《技术方案初稿》，本次按直接指令先行产出 Demo（2.3）。
2. **面主题色**：UU = 琥珀（`#EF9F27`，取自 `assets/avatars/uu.svg`）、Mixt = 蓝（`#378ADD`，取自 `assets/avatars/mixt.svg`）。换色只需改 `demo.css` 第 3 节的变量。
3. **Mixt 的分类与文章**：PRD 3.5 规定 Mixt 面分类为空；Demo 中为展示隔离效果使用了示例分类与示例文章，页面内已放置说明横幅。
4. **未包含的页面**：分类页 / 标签页 / 作者页 / 关于本站页（M4）、全站搜索 / RSS（M6）。点击相关入口会给出说明性 toast 而非死链。
5. **翻转动画**：受 file:// 与 Demo 单页形态限制，用「卡牌翻出 90° → 整页跳转 → 另一面从 90° 翻入」模拟 PRD 4.2 的 pushState 无刷新翻转；正式实现中为 SPA 式翻转 + `popstate` 反播。v4 起为**卡牌式翻转**：缓慢高光带扫过后，背景与内容在 90° 瞬间同时切换（跨页用 `sessionStorage` 标记衔接高光后半程）。
6. **动效增强（2026-09-13 v3 震撼版 → v4 卡牌翻页）**：入口页翻牌历经两轮增强——v2 卡片倾斜、叠卡错出、粒子与冲击波；v3 蓄力帧（14% scale 1.18）、中点放大 scale 1.85、卡片微发光、stage-tilt 侧摆、S2 粒子喷泉 + 双重冲击波、S3 双连爆 + 全屏闪光、入场 scale 9。**v4（同日）面间翻页改为纯卡牌式翻转 + 高光**（移除粒子/闪光，入口页粒子保留）。所有特效仅动画 `transform`/`opacity`，元素在动画结束后移除。
7. **~~与 PRD 4.2 的冲突~~（已解决）**：v2 引入粒子时与 PRD 4.2「禁止粒子等特效」冲突，用户裁决**保留动效并修订 PRD**——PRD v1.3 已将禁令拆为「常驻禁止 + 转场瞬间允许」（论证见 `02-产品决策记录.md` 7.7）。本 Demo 的特效范围即该条款的具体化。
8. **⚠️ 新冲突待裁决（2026-09-13 v4）**：本次按用户指令引入了两项**常驻**视觉元素——① 面首页 Hero 整屏高清背景图；② 正文区同图**常驻虚化**背景（`filter: blur(26px)`）。PRD 4.2「常驻禁止」条款字面上包含「模糊」，与 ② 冲突。建议下次 PRD 修订时把「面视觉背景（含虚化）」从「特效」中豁免——它属于视觉风格而非动效。在修订前，此项为**用户直接指令下的有意识偏离**。
9. **入口页背景图（已接入）**：三张背景图已齐——UU 面 `assets/bg-uu.jpg`、Mixt 面 `assets/bg-mixt.jpg`、入口页 `assets/bg-entry.jpg`（AI 生成的晨昏线天空，左琥珀对应 UU、右深蓝对应 Mixt，已去水印并压至 224KB）。换图只需改 `demo.css` 里对应的 CSS 变量。
10. **背景图必须用同目录相对路径**：`demo.css` 位于 `assets/` 内，写 `url("assets/x.jpg")` 会被解析成 `/assets/assets/x.jpg` → 404（本 Demo 踩过，见提交 `c10cd1e`）。正确写法是 `url("x.jpg")`。
10.1 **文章正文方框与拖边界**：正文被一个方框框住，拖动方框的左/右边界调整阅读宽度（容器居中，故边界每移动 1px 宽度变化 2px）；双击恢复默认（900px），宽度存 localStorage；≤1020px 单栏断点下不提供。
11. **关于本站的入口（待 UU 确认）**：PRD v1.2 写的是「入口仅由入口页底部一行小字进入」。Demo 里除了入口页小字，**两面页脚的站点级链接也放了入口**——按字面执行 PRD 应删掉页脚那条。留待 UU 裁决。
12. **Demo 的持久化范围**：写作台的数据存在**浏览器 localStorage**（键 `uum-demo-store-v1`），换浏览器/清缓存即回到初始数据。真实实现是 M5 的 Decap CMS + GitHub OAuth，提交 Markdown 进私有仓库。密码同样是前端硬编码的 Demo 值，**不具备任何安全性**，正式实现必须走 OAuth。
13. **无头截图走 file://**：本机 `python -m http.server` 与 Chrome 之间存在沙箱隔离（Chrome 连不上 127.0.0.1，拿到的是错误页），因此截图证据统一用 `file://` 协议拍摄（Demo 已做 file:// 兼容）。
